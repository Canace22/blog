## 骨架

第一幕让观众认识角色和他想要的东西，第二幕让阻碍一次比一次大，第三幕正面决战、付出或躲开代价。

| 幕     | 《海底总动员》里发生了什么                 | 这一步的作用           |
| ----- | ----------------------------- | ---------------- |
| 第一幕   | 梗鱼袭击，马林只剩儿子尼莫；尼莫第一天上学，马林处处管着他 | 日常，立起缺点（胆小、过度保护） |
| 第一幕   | 尼莫赌气碰船，被潜水员抓走                 | 激励事件：事情找上门       |
| 第一幕结束 | 马林遇到多莉，第一次离开珊瑚礁游进大海           | 主动选择：主角接住问题      |
| 第二幕   | 鲨鱼聚会 → 水母群 → 鲸鱼嘴里放手多莉         | 外部升级，一步步逼近缺点     |
| 第三幕   | 多莉被渔网捞住，马林放手让尼莫钻进网里去救         | 代价最大时突破缺点        |

## 第一幕：激励事件 vs 主动选择

**事件推动开头，选择推动故事。** 第一幕的终点是主角主动跨过门槛、回不了头的那一刻，不是打破日常的那件事。

```text
日常 ──→ 激励事件 ──→ 犹豫/挣扎 ──→ 主动选择 ══▶ 第二幕
         事情找上门                    主角接住它
```

* **我的第一反应选了“尼莫被抓”：** 那是激励事件，马林是被动的。第一幕真正结束在马林自己游出珊瑚礁。

* **洋流反例：** 如果马林是被洋流冲出去的，胆小就被绕过去了，故事没让他为缺点付出任何东西，第一幕结尾就变弱。

* **为什么选择重要：** 角色在压力下的选择，是观众认识他最快的方式。主角越被动，观众越难站到他那边。

## 第二幕：外部升级 + 逼近缺点

外部阻碍越来越大，同时一步步把主角逼到必须面对自己缺点的地方。

| 关卡   | 外部危险        | 马林这个人变了吗                          |
| ---- | ----------- | --------------------------------- |
| 鲨鱼聚会 | 鲨鱼闻到血味失控    | 没有，只是逃命                           |
| 水母群  | 多莉被蛰伤，差点失去她 | 没有，只是逃命                           |
| 鲸鱼嘴里 | 可能被吞下去      | **变了**：第一次放手、相信别人，和“什么都要抓在手里”正面对撞 |

**预演：** 鲸鱼那关放的是多莉，等于提前给观众看了一次“他能放手”，第三幕再放手时就既意外又合理。

## 第三幕：代价最大时突破缺点

多莉和一群鱼被渔网捞住，尼莫要自己钻进网里带大家往下游。马林可以拦住他，也可以放手；他选了放手。这一下同时做到三件事：

1. **代价最大：** 尼莫可能再次失去，这次是马林亲手放走的。

2. **缺点被彻底突破：** 上次放的是多莉，这次放的是他最怕失去的儿子。

3. **预演兑现：** 观众在鲸鱼那里已经看过他放手一次。

## 想要 vs 需要

第一幕到第二幕追的是“想要”，第三幕兑现的是“需要”。好故事的高潮，往往是主角为了“需要”冒着失去“想要”的风险。

|             | 马林        |
| ----------- | --------- |
| 想要（他以为的目标）  | 找回尼莫      |
| 需要（他真正得学会的） | 放手，相信儿子能行 |

## 自检清单

* 第一幕里缺点立起来了吗？

* 激励事件之后，主角是**自己选择**跨过门槛的吗？这个选择有没有让他为缺点付出什么？

* 第二幕的阻碍只是更危险，还是在一步步逼近缺点？

* 高潮前有没有一次预演？

* 高潮时，主角是否为了“需要”冒着失去“想要”的风险？
