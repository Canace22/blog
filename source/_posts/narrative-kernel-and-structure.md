## 故事内核四格

所有叙事框架底下都压着这一句：一个**角色**想要**某样东西**，但有**阻碍**挡着，如果失败会付出**代价**。阻碍让故事有戏可看，代价让人揪心。

| 角色             | 想要         | 阻碍               | 代价        |
| -------------- | ---------- | ---------------- | --------- |
| 小丑鱼马林（《海底总动员》） | 找回被抓走的儿子尼莫 | 大海很危险；他自己胆小又过度保护 | 永远失去唯一的家人 |

马林的阻碍有一半在他自己身上（胆小），这种“内在阻碍”往往是故事最有味道的地方。

## 检验代价：追问“那又怎样”

代价不是“想要”的反面。对失败结果追问“那又怎样”，直到答案让人揪心为止。

1. 马林找不回尼莫 → 那又怎样？

2. 他会失去尼莫 → 那又怎样？

3. 尼莫是他在妻子和其他孩子遇害后**仅剩的家人**，他会彻底变成一个人。← 到这一层才揪心

**我踩的坑：** 林克的代价我填的是“失败了就救不出公主”，这只是把“想要”反过来说了一遍。往下追：塞尔达已压制盖侬 100 年、力量快耗尽，她撑不住海拉鲁就会毁灭。

## 代价要被感受到，不是被说出来

旷野之息把代价说出来了，但玩法上告诉你“不急”，所以听完还是“那又怎样”。让代价被感受到靠三点：

|      | 《姆吉拉的假面》的月亮   | 旷野之息的盖侬      | 卓拉领地的大雨 |
| ---- | ------------- | ------------ | ------- |
| 看得见  | 天天挂在头顶        | 城堡在远处，平时注意不到 | 看得见     |
| 在逼近  | 3 天倒计时，一天比一天近 | 100 年都没事     | 挂多久都不变  |
| 真会发生 | 时间到了真砸下来      | 你不去，它永远不来    | 大坝永远不会垮 |

* **开放世界和紧迫感天生打架：** 一个承诺“想逛多久都行”，一个要求“快去”。旷野之息选了自由，整体放弃了事件层面的代价，连地区小危机也只做到了“看得见”。

* **硬加倒计时有风险：** 《辐射》初代找水芯片有期限，很多玩家逛着逛着时间耗尽，后来补丁把期限放宽了。

* **让拖延真有后果：** 《质量效应 2》船员被抓后若先去做别的任务，回来会有人已经死了。它放在接近结尾、地图已收窄的时候，没破坏前面的自由。

## 代价的三种类型

事件代价依赖时间压力，开放世界很难用；情感和内在代价不依赖时间，开放世界也能用。

| 类型   | 失去的是什么     | 例子        | 依赖时间压力 |
| ---- | ---------- | --------- | ------ |
| 事件代价 | 外部世界会发生的坏事 | 世界毁灭、大坝崩溃 | 是      |
| 情感代价 | 和某个人的关系    | 失去某人、辜负某人 | 否      |
| 内在代价 | 角色自己       | 变成自己讨厌的样子 | 否      |

## 内核 vs 结构

原理不分类型，手段分。**内核**（四格）管“为什么让人在乎”，所有类型一样；**结构**管“按什么顺序、由谁决定顺序”，随类型变。

| 结构     | 顺序谁定     | 典型形态                      | 例子                  |
| ------ | -------- | ------------------------- | ------------------- |
| 线性     | 作者       | 三幕式：建立 → 对抗 → 解决          | 大多数电影、线性剧情游戏        |
| 分支     | 作者预设，玩家选 | 关键选择导致不同走向和结局             | 《底特律：变人》            |
| 开放/模块化 | 玩家       | 松框架 + 能任意顺序完成的小块，每块自己有小闭环 | 旷野之息：四神兽任意顺序、回忆乱序收集 |

越往下，作者对顺序的控制越少，“高潮放结尾”“代价逐步逼近”越难用，只能放进每个小块内部去做。

**案例：旷野之息的回忆。** 内容本身有情感代价（塞尔达的挫败、对林克从排斥到信任），但顺序交给玩家，在乎很难一步步叠上去，这是**结构**问题。任天堂的补救：冒险日志按时间顺序重排回忆，最后一段关键回忆要找齐其他的才解锁——能让的顺序都让了，最重的一块还是锁在结尾。

## 自检清单

* 四格都填得出来吗？阻碍里有没有一部分在角色自己身上？

* 代价是不是只是“想要”的反面？追问过“那又怎样”吗？

* 代价看得见、在逼近、真会发生吗？还是只是被说出来？

* 结构允许用事件代价吗？不允许的话，换成情感或内在代价了吗？

* 顺序交给玩家时，最重的那一块锁在结尾了吗？
