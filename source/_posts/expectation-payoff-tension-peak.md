## 起点：游戏设计的三层

好的设计是三层对齐的：剧情最紧张的时候，玩法也最难、节奏也最快。对不齐时，玩家会觉得“剧情很燃但我在跑腿”。

| 层     | 管的是什么               | 典型问题            |
| ----- | ------------------- | --------------- |
| 玩法循环  | 玩家每分钟在“做什么”，为什么想继续做 | 核心循环、反馈、奖励      |
| 关卡与节奏 | 这些“做”怎么排顺序、怎么变化     | 引导、难度曲线、紧张/放松交替 |
| 叙事结构  | 玩家为什么在乎这件事          | 角色动机、冲突、三幕、环境叙事 |

## 案例一：塞尔达四神兽

神兽的张力峰值放在了开头，所以打完会觉得“也就那样”。我的原始感受：接近时有威慑感，打起来有点难，掌握技巧后就平了。

```text
情绪
 ▲   威慑感
 │   ╭──╮
 │  ╱    ╲   难打
 │ ╱      ╲──╮
 │╱           ╲___ "也就那样"
 └──────────────────▶ 时间
  接近神兽   进入内部   打Boss   结束
```

* **关键概念：期待与兑现。** 前面做出的“承诺”越大，后面的“兑现”就得跟上，否则玩家觉得落空。

* **接近阶段把承诺拉满：** 巨大体型、对村镇的威胁、和希多/提巴并肩作战，三层在这里是对齐的。

* **高潮没有兑现：** 四只灾厄盖侬套路很像，摸清规律后只剩“执行”，没有新东西冒出来。

* **对照：《旺达与巨像》** 威慑感和战斗是同一件事（爬在巨像身上打），敬畏感一直持续到最后一击。

## 误区：兑现感不够 ≠ 加难度

难度只是五根杠杆里的一根，而且是最危险的一根：难度超过玩家能力会直接流失，比“也就那样”严重得多。很多让人记很久的 Boss 战一点都不难，靠的是后面几根。

| 杠杆   | 做法举例                | 难度变吗    |
| ---- | ------------------- | ------- |
| 难度   | Boss 血更厚、伤害更高       | 变       |
| 新鲜感  | Boss 最后阶段来一招前面从没见过的 | 基本不变    |
| 叙事揭示 | 打赢的瞬间揭开一段关键剧情       | 不变      |
| 演出   | 音乐、镜头、场景在最后一刻突然变化   | 不变      |
| 身份变化 | 用刚夺回的神兽力量反打 Boss    | 甚至可以更简单 |

## 案例二：岩石巨人

岩石巨人不难，却让人印象很深，因为它的张力峰值落在结尾。

| 时刻 | 发生了什么          | 起作用的杠杆                    |
| -- | -------------- | ------------------------- |
| 开头 | 一堆石头走近了突然站起来   | 新鲜感 + 演出（期待在一瞬间制造，没有过长铺垫） |
| 过程 | 打的过程本身有趣，还会掉宝物 | 奖励：即时、看得见                 |
| 结尾 | 崩塌动画 + 矿石散一地   | 演出：情绪峰值放在最后一刻             |

```text
神兽：    高 ──→ 中 ──→ 平      峰值在开头，越打越淡
石头人：  低 ──→ 惊喜 ──→ 峰值   峰值在结尾，打完正爽
```

## 结论与自检清单

两个例子难度都不高，区别在于**张力的高点放在哪**。这条原则可以拿去检验任何关卡、任务，也可以检验剧本里的一场戏。

* 最有分量的东西有没有留到最后？

* 前面的“承诺”和后面的“兑现”配得上吗？

* 奖励是不是即时、看得见？

* 想加强高潮时，先试了难度以外的杠杆吗？

* 高潮时玩法、节奏、叙事三层是否对齐？
